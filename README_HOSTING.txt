BIP26 Guided Portal Hosting

This is a static website. Upload the whole folder exactly as-is.

Free hosting options:
1. GitHub Pages: commit this folder to a GitHub repo, then Settings > Pages > Deploy from branch.
2. Netlify: drag and drop the folder or ZIP into Netlify Drop.
3. Vercel: import the GitHub repo.
4. Own server: copy the folder to your web root, e.g. /var/www/html/bip26.

Keep folder names unchanged:
/docs for PDFs, /code for Arduino sketches, /quizzes for quiz HTML, /assets for images.
